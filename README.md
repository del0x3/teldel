# 🛡️ Android Dopamine Detox & Digital Hardening Suite

Комплексный набор инструментов и скриптов автоматизации для глубокого аудита использования смартфона (Android / Samsung One UI), устранения дофаминовых петель, закрытия цифровых лазеек и превращения телефона в строгий минималистичный инструмент («Серый камень»).

---

## ⚡ Быстрый старт (Запуск в 1 клик)

### 1. Подготовка смартфона:
1. Откройте на телефоне: **Настройки** → **Сведения о телефоне** → **Сведения о ПО**.
2. Нажмите 7 раз на **«Номер сборки»** (активирует режим разработчика).
3. Перейдите в появившееся меню: **Параметры разработчика** → включите **«Отладка по USB»**.
4. Подключите телефон кабелем к ПК и выберите **«Всегда доверять этому компьютеру»** при появлении диалога на экране.

### 2. Запуск на Windows:
Просто дважды кликните по:
```cmd
phone_manager.bat
```
> **Примечание:** Если у вас не установлен ADB (Android Debug Bridge), скрипт автоматически обнаружит это и предложит скачать официальный пакет Google Platform-Tools прямо в папку проекта в один клик!

## 🧭 Возможности системы

### 1. 📱 Менеджер периметра (`phone_manager.bat` / `phone_manager.ps1`)
Интерактивное консольное меню для быстрого управления устройством:
* **[1] Временно включить Google Play Store** — разморозка магазина для обновления критических приложений (банки, аутентификаторы).
* **[2] Выключить Google Play Store** — мгновенная блокировка магазина (`pm disable-user`) для предотвращения импульсивных установок.
* **[3] Трансляция экрана на ПК** — запуск зеркалирования и управления через `scrcpy`.
* **[4] Переключатель Ч/Б <--> Цвет** — быстрый перевод экрана в строгий монохром (отсекает 80% дофаминового притяжения интерфейса) и обратно.
* **[5] Экспресс-аудит** — мгновенная проверка температуры, батареи, RAM, DoT DNS и закрытых векторов.
* **[6] Тотальная зачистка периметра** — удаление браузеров (Chrome, Samsung Internet, HTMLViewer), YouTube, магазинов приложений, Termux, второго пространства Knox (Secure Folder), блокировка VPN-диалогов, запрет установки сторонних APK и принудительный DoT CleanBrowsing DNS.

---

### 2. ⚡ Автоматическая трансформация (18 шагов) и Откат (Rollback)
* **`apply_minimalism.bat` / `apply_minimalism.ps1`** — пакетный запуск полной трансформации смартфона за один проход (ускорение анимаций в 2 раза, монохромный режим, отключение мусорных системных пакетов, настройка DoT DNS, оптимизация экрана).
* **`restore_defaults.bat` / `restore_defaults.ps1`** — 1-кликовый возврат всех настроек в заводское состояние (возврат цветного экрана, стандартных анимаций, включение Google Play, возвращение стоковых системных параметров).

---

### 3. 📊 Аналитика дофамина и экранного времени (`collect_stats.bat` / `collect_stats.py`)
Сбор и анализ сырой телеметрии ядра Android:
* Запуск сбора статистики в 1 клик:
  ```cmd
  collect_stats.bat
  ```
  Скрипт снимает актуальный дамп `dumpsys usagestats`, выполняет парсинг и генерирует данные для визуализации.

#### Скрипты аналитики:
* **`deep_dopamine_miner.py`** — вычисляет:
  * Суточный циркадный ритм активности (распределение включений по часам 00:00–23:00).
  * Компульсивные микро-заглядывания (<20 секунд).
  * Длинные непрерывные сессии залипания (Binge sessions > 30 минут).
  * Петли переключения контекста (например, *Telegram ⇄ Рабочий стол*).
* **`show_deep.py`** — текстовый вывод сводки активности и дофаминовых петель прямо в терминал.
* **`print_7days.py`** — вывод экранного времени и количества запусков приложений за последнюю неделю.
* **`parse_usage.py`** / **`parse_multi.py`** — детальный разбор интервалов времени и агрегация по приложениям.

---

### 4. 🌐 Интерактивные Web-Дашборды и Отчеты
В проект включены автономные HTML-отчеты (работают локально в любом браузере, не требуют сервера):
* **`dopamine_interactive_dashboard.html`** — футуристичный дашборд на Chart.js: графики циркадного ритма, эквивалент упущенного потенциала в книгах/тренировках, анализ петель привычки.
* **`step_by_step_transformation.html`** — интерактивный чек-лист трансформации телефона по этапам (шаги 1–18): от установки лаунчера до запечатывания периметра.
* **`full_system_transformation_report.html`** — полный аналитический отчет по архитектуре защиты смартфона.

---

### 5. 🪶 Минималистичный лаунчер и аудит APK
* **`download_launcher.py`** — автоматически находит и скачивает последний релиз открытого минималистичного лаунчера [Olauncher](https://github.com/tanujnotes/Olauncher) через GitHub API.
* **`audit_olauncher.py`** — сканирует DEX-байткод скачанного APK на отсутствие рекламных и трекинговых SDK (Google Ads, Facebook, Unity, AppLovin и т.д.).
* **`dyn_rename.py`** / **`rename_all_fast.py`** — автоматизация ADB UI Automator для быстрого переименования однотипных иконок (например, разделение нескольких приложений с названием «Authenticator» на «MS_Auth», «Bitwarden_Auth», «Google_Auth»).

## 📋 Системные требования

* **ОС:** Windows 10 / 11 (PowerShell 5.1+ / 7+)
* **Смартфон:** Android 9.0+ (протестировано на Samsung One UI 6 / Galaxy A16)
* **Python:** 3.8+ (только стандартная библиотека! Сторонние `pip` пакеты не нужны)
* **ADB & scrcpy:** Опционально (при отсутствии ADB скрипт предложит скачать его автоматически; [scrcpy](https://github.com/Genymobile/scrcpy) рекомендуется для зеркалирования).
